# 啵啵语音记账（智能语音记账）

> 当前版本：**1.0.0**

基于微信小程序云开发（CloudBase）的语音记账应用。用户通过语音或文字即可完成记账，由大模型自动识别金额、分类、时间等结构化信息，并提供账本管理、消费分析、博文社区等能力。

## 功能特性

- **语音记账**：按住录音 → 云端 ASR 语音识别 → 大模型结构化解析（类型 / 金额 / 大类 / 细类 / 时间 / 地点），支持多笔连记、相对时间换算
- **文本记账**：直接输入文字描述，走同一套 AI 解析流程
- **多账本**：个人账本 + 组队账本（最多 10 人，邀请链接 24 小时有效）
- **消费分析**：收支统计、分类占比饼图、月度热力图、每日消费日历、细类下钻
- **AI 消费画像**：基于账本数据生成消费偏好与建议报告
- **记账明细**：记录筛选（类型 / 日期 / 地点）、编辑、删除、删除整月 / 整天、拍照配图
- **博文社区（发现页）**：按分类浏览、点赞、楼中楼评论、分享计数、删除管理
- **用户体系**：微信头像昵称登录，头像上传云存储

## 技术架构

- 微信小程序原生（WXML / WXSS / JS）+ 云开发
- AI 能力：微信云开发 `wx.cloud.extend.AI`（hy3 大模型）
- 语音识别：阿里云 ASR（API Key 存于云存储 `config.json`，由 `getConfig` 云函数读取，前端不接触密钥）
- 数据库：云数据库；图片 / 录音：云存储

## 项目结构

│   ├── asr/                   # 语音识别（调用阿里云 ASR）

│   ├── getOpenId/             # 获取用户 OpenID
│   ├── posts/                 # 博文（增删查 / 点赞 / 评论 / 分享计数）
│   ├── team/                  # 账本（创建 / 删除 / 邀请 / 成员管理）
│   └── teamRecords/           # 记账记录（增删改查 / 聚合统计 / 配图）

## 部署步骤

1. 用微信开发者工具导入项目根目录，确认 AppID 与云环境 ID 正确
2. 在云开发控制台确认已开通云环境（`voiceledger`）
3. 将 `cloudfunctions` 下所有云函数**右键上传并部署**（云端安装依赖）
4. 在云存储中上传 `config.json`（内容：`{"aliyun_api_key": "你的阿里云语音合成 Key"}`），
   并复制其 fileID 更新到 `cloudfunctions/getConfig/index.js` 中的 `fileID` 常量
5. 数据库集合（`users`、`notebooks`、`records`、`posts`、`post_likes`、`post_comments`）由云函数首次调用时自动创建

## 数据库集合

| 集合 | 说明 |
|------|------|
| `users` | 用户（openId / 昵称 / 头像） |
| `notebooks` | 账本（成员、邀请信息、自定义图标） |
| `records` | 记账记录（类型 / 金额 / 分类 / 时间 / 地点 / 配图） |
| `posts` | 博文（标题 / 正文 / 图片 / 点赞评论分享计数） |
| `post_likes` | 博文点赞记录 |
| `post_comments` | 博文评论（支持楼中楼） |
